# 🤖 AI-buddy: ИИ-наставник для стажёров Авито

Прототип AI-помощника, разработанный командой **Чугун** в рамках хакатона **Hack&Change 2026** (кейс от Авито).

AI-buddy помогает стажёрам быстрее адаптироваться: отвечает на вопросы по внутренним инструментам (RAG), выполняет действия через корпоративные сервисы (создание заявок на доступ, отправка сообщений) и помогает найти ответственных за микросервисы.

> 🚧 **Статус проекта:** В активной разработке (День 1 из 5). Нижеописанные команды запуска будут доступны после завершения настройки инфраструктуры.

## 🛠 Технологический стек

Frontend: добавлена основа Vite + React + TypeScript с Zustand и Zod.
Локальный запуск и проверки описаны в [`frontend/README.md`](./frontend/README.md).
Пользовательский чат ещё не реализован; Frontend в Docker Compose пока остаётся заглушкой.

*   **Backend:** Go (мок-сервисы, интеграции)
*   **Frontend:** React + TypeScript + Vite + Zustand
*   **AI Service:** Python + FastAPI + Ollama (локальная LLM Qwen)
*   **База данных:** PostgreSQL + pgvector (для RAG)
*   **Инфраструктура:** Docker Compose, GitHub Actions (CI)
*   **Методология:** SDD (Spec-Driven Development на базе `spec-kit`)

## 🚀 Как запустить (Будет доступно в День 2)

Проект будет запускаться одной командой через Docker Compose.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/naumnovikov/hack_and_change_2026_chugun.git
cd ai-buddy

# 2. Скопировать переменные окружения
cp .env.example .env

# 3. Запустить все сервисы
docker compose up --build
