# AI-сервис: основа первого дня

`main.py` — программа FastAPI. Она принимает сообщение и возвращает заранее заданный ответ. LLM, RAG, права пользователя и корпоративные действия пока не подключены. Текст ответа не означает, что заявка создана или сообщение отправлено.

`tests/test_chat.py` — автоматические проверки программы. `requirements.txt` фиксирует все версии библиотек, включая инструменты тестирования; `requirements.in` перечисляет прямые зависимости. `Dockerfile` описывает окружение Python 3.11 и команду запуска.

`psycopg[binary]` подготовлен для будущего подключения PostgreSQL, `openai` — для совместимого API модели. Сейчас они не используются обработчиком. Binary-вариант psycopg включает необходимые клиентские библиотеки и не требует отдельной установки libpq ([документация](https://www.psycopg.org/psycopg3/docs/basic/install.html)). `httpx` нужен TestClient, `pytest-cov` — отчёту о покрытии.

## Запуск в Docker

Из корня репозитория, в PowerShell:

```powershell
docker compose up --build -d ai-service
```

Команда собирает и запускает только AI-сервис. База данных и Ollama для этой заглушки не нужны. Затем отправить сообщение:

```powershell
Invoke-RestMethod -Uri http://localhost:8000/chat -Method Post -ContentType 'application/json; charset=utf-8' -Body '{"message":"Hello"}'
```

Ожидаемый ответ: поле `reply` со значением `Hello from AI`. Открытие `/chat` в браузере посылает GET, а этот адрес принимает POST. Для интерактивной проверки открыть `http://localhost:8000/docs`, выбрать `POST /chat` → Try it out → Execute.

## Тесты

```powershell
docker compose run --build --rm --no-deps ai-service python -m pytest
```

Проверяются успешный ответ, пустое/слишком длинное сообщение, неправильный JSON, тип данных и лишние поля. При успехе видны `passed` и таблица покрытия. Порог установлен в 81%, чтобы требование строго >80% выполнялось. XML-отчёт появляется в `ai-service/coverage.xml` благодаря volume Compose; он не коммитится.

## Временный контракт

- `POST /chat`, JSON: `{"message":"Привет"}`.
- `200`, JSON: `{"reply":"Hello from AI"}`.
- Сообщение: строка от 1 до 8000 символов после удаления пробелов по краям; другие поля запрещены.
- Некорректный запрос: `422`; другой HTTP-метод: `405`.

Это проверка транспорта, не конечный контракт Go ↔ Python. Контекст пользователя и цикл tools появятся по `specs/agent.spec.md` после согласования с Backend. Собственную авторизацию здесь не создаём.

Машиночитаемый контракт этого этапа: `specs/openapi.yaml` (из корня репозитория). Он описывает только AI-сервис, не будущие Go-моки.

## Результат проверки 11.11.2026

На Windows/Python 3.12.14 прошли 13 тестов, покрытие `main.py` — 100% (12 исполняемых строк). Реальный запуск uvicorn и HTTP POST вернули `200` и `{"reply":"Hello from AI"}`; временный сервер после проверки остановлен. Импорты psycopg/openai и `pip check` успешны. Разрешение зафиксированных зависимостей для Linux/Python 3.11 проверено через pip dry-run. Docker недоступен в текущей среде: сборка контейнера и удалённый CI пока не проверены. По Docker-first задача ещё не считается полностью закрытой.

Локальный запуск допускается для отладки, но не заменяет проверку в Docker. Основа реализации и тестирования: [тело запроса FastAPI](https://fastapi.tiangolo.com/tutorial/body/), [TestClient и pytest](https://fastapi.tiangolo.com/tutorial/testing/).
