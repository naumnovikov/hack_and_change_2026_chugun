## Ручная приёмка будущего RAG

| Вопрос | Ожидаемый результат |
|---|---|
| Что такое SPT? | Объяснение из spt.md со ссылкой на первоисточник |
| Чем Crash отличается от Bug? | Различие по spt.md со ссылкой |
| Что означает TDR? | Объяснение из tdr.md со ссылкой на первоисточник |
| Когда после TDR переходят к реализации? | После завершения доработок и повторного ревью, по tdr.md |
| Что такое ZBP? | В этом корпусе подтверждённый источник не найден; предложить уточнить у наставника |
| Кто владелец billing и как ему написать? | Корпус не содержит сведений о владельце; не выдумывать сотрудника |

Отрицательные вопросы — проверки поведения, не документы для индексации.
Не индексировать этот README: иначе ожидаемые ответы тестов станут
ложными источниками. Для минимального корпуса индексировать только
spt.md и tdr.md, перечисленные в sources.json. Отсутствие определения здесь не доказывает его отсутствие
в других материалах Playbook.
