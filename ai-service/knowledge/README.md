# База знаний: открытые источники AvitoTech

Подготовлена для вопросов стажёров о терминах и инженерной работе.
Это curated подборка открытых публикаций, а не закрытая внутренняя база знаний.

Открытые публикации закреплены на commit
`0c1d2aa1501ca6889357908f54b12695f0534e48`. Это редакционные пересказы,
а не закрытые регламенты; корпус не подтверждает актуальность внутренних
процедур конкретной команды на текущую дату.

В ответе указывать источник как открытую публикацию AvitoTech Playbook.
Набор не содержит персональных данных, ключей или закрытых инструкций.
Конкретные правила команды — например, порядок перевода задачи в Done,
обязательный шаблон PR или сроки ревью — нельзя выводить из общих принципов.

Словарь синонимов находится в `../synonyms.py`. Он сопоставляет
разговорные варианты («таска», «фича», «преза») с поисковыми терминами,
но сам не является источником фактов. Неизвестные термины по-прежнему
должны подтверждаться найденным текстом источника.

## Ручная приёмка будущего RAG

| Вопрос | Ожидаемый результат |
|---|---|
| Что такое SPT? | Объяснение из spt.md со ссылкой на первоисточник |
| Как сделать таску? | Найти принципы проектирования и тестирования; попросить контекст для конкретных шагов |
| Чем Crash отличается от Bug? | Различие по spt.md со ссылкой |
| Что такое «преза»? | Распознать как «презентация»; сообщить, что найденные материалы не описывают шаблон презентации |
| Что означает TDR? | Объяснение из tdr.md со ссылкой на первоисточник |
| Когда после TDR переходят к реализации? | После завершения доработок и повторного ревью, по tdr.md |
| Какие термины есть в источниках? | Перечислить SPT, TDR, Bug, Crash, Feature, Scrum, DX и Continuous Delivery из glossary.md |
| Что такое ZBP? | В этом корпусе подтверждённый источник не найден; предложить уточнить у наставника |
| Кто владелец billing и как ему написать? | Корпус не содержит сведений о владельце; не выдумывать сотрудника |
| Каков процесс сдачи PR в конкретной команде? | Общий Playbook не задаёт точный процесс; предложить уточнить его у команды или наставника |

Отрицательные вопросы — проверки поведения, не документы для индексации.
Не индексировать этот README: иначе ожидаемые ответы тестов станут
ложными источниками. Индексировать только материалы, перечисленные в
sources.json. Отсутствие определения в корпусе не доказывает его
отсутствие в других материалах Авито.

## Граница текущего шага

Подготовлены пересказы открытого Playbook, алиасы, контрольные вопросы,
sources.json и разбиение в chunking.py.
Формат и приёмка описаны в specs/rag-chunks.spec.md от корня репозитория.
load_corpus(Path("knowledge")) возвращает индексируемые чанки без сетевых запросов.
Embeddings, атомарная загрузка в pgvector и генерация реализованы в AI runtime.
Порядок запуска и проверки: ../README.md. Для индексации: python -m ingest.
