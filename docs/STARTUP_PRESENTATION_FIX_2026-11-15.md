# Исправление запуска, контекста и презентации

Ветка: fix/presentation-startup-routing, исходный main: 954e4f8.

- Скрипты создают криптографический временный общий токен Go/AI, если он не
  задан. Явно заданный короткий токен отклоняется. .env не перезаписывается.
- Локальная Ollama готовится только для provider=ollama и hostname=ollama;
  внешний API или внешняя Ollama не запускают ненужную локальную модель.
  Используются настроенные имена моделей, учитывается суффикс :latest.
- Исправлены PowerShell argument binding и UTF-8 BOM для Windows PowerShell;
  для Bash закреплены LF через .gitattributes.
- Явные команды презентации расширены, отрицания, вопросы о процедуре и
  произвольные identity/темы не принимаются как разрешение на действие.
- Go передаёт две последние пары реплик, как допускает существующий AI-контракт;
  сохранены ограничения источников и изоляция сессий. Это не полная память чата.
- Для Ollama JSON Schema остаётся в constrained decoding, но не дублируется
  текстом в промпте. Для API схема в промпте сохранена. Ответ презентации
  запрашивается компактным; grounding и покрытие всех задач не ослаблены.

  Полный запуск на macOS на этой машине не проверялся.
